LSF HPC Demo 平台介绍

基于 IBM Spectrum LSF 构建的 HPC（高性能计算）解决方案演示环境，覆盖集群部署、作业调度、HPC 应用运行、监控告警的全链路演示。

一、方案架构

组件说明
LSF Master (node211)mbatchd 调度核心，配置/集群文件，NFS 导出 /data/lsf 与 /data/hpc
计算节点 ×4node212/213/215/219，sbatchd/res 守护进程，每节点 8 slot
Demo Portal任务执行页面一键提交 LSF/HPC 作业；Ansible 全生命周期管理（安装/配置/测试/扩容）
监控栈Prometheus 采集 node_exporter(CPU/内存/网络/磁盘) + lsf_exporter(作业/槽位/队列)，Grafana 可视化

二、HPC 应用场景与背景

本 demo 集成了 5 个源自真实超算场景的 HPC IO/计算基准，加上 2 个组合型应用：

应用场景背景
HACC_IO宇宙学模拟 (Hardware/Hybrid Accelerated Cosmology)，粒子数据集体 IO 读写，源自美国 Argonne 实验室宇宙模拟项目
HACC_OPEN_CLOSEHACC 变体：反复打开/关闭文件测试元数据与小 IO 性能
BTIONAS Parallel Benchmark 的块状 IO 测试，MPI-IO 集合写，航空航天 CFD 检查点场景
MADbench宇宙微波背景 (CMB) 分析 IO 基准，源自 MAP/Planck 卫星数据处理
s3d_io湍流燃烧直接数值模拟 (S3D) 的 IO 模式，Teragrid 主流负载
MIXED 混合应用六阶段组合负载：串行预处理 → MPI 计算 → 数组式并行 → MPI 集体 IO → 依赖链 → 汇总校验，模拟真实业务流水线（约30分钟）
STRESS 压力测试3 批次×7 子作业共 48 槽需求压满 40 槽集群，制造排队压力验证调度器吞吐

三、Demo 中 HPC 如何使用

1. 提交作业

「任务执行」页选择 HPC 应用 → 点击 ▶ EXECUTE，门户自动 SSH 到 Master 执行 bsub。等价命令示例：

bsub -J demo_HACC_IO -n 8 -R "span[ptile=2]" -o /data/hpc/lsf_logs/%J.out /data/hpc/lsf_bench.sh HACC_IO

2. 监控作业

「LSF 集群」页实时查看 bhosts/bqueues/bjobs（自动刷新 5/10/20/30 秒可选，支持立即刷新），并显示集群负载趋势图；「性能监控」页内嵌 Grafana 大盘看 CPU/内存/网络/槽位占用。

3. 查看结果

「作业历史」页回放任意作业的终端输出；作业日志在 /data/hpc/lsf_logs/，数据输出在 /data/hpc/test_out/。

4. 取消作业

执行页右侧「■ 取消全部作业」一键 bkill 所有执行中/排队中的 HPC 作业（有二次确认）。

四、HPC 应用与 LSF 的集成

1. 通用调度脚本

所有基准通过统一入口 /data/hpc/lsf_bench.sh 调度，脚本从 LSF 环境变量 $LSB_MCPU_HOSTS 动态生成 MPI hostfile，实现 LSF 分配到哪里、mpirun 就跑到哪里。

2. 集成要点

环节实现
槽位↔进程映射-n 8 -R "span[ptile=2]" → 4节点×2slot，hostfile 按分配自动生成，MPI rank 与 slot 对齐
共享存储Master NFS 导出 /data/hpc，全部节点可读写，二进制/脚本/日志/数据共享
免密互信lsfadmin 全节点 SSH 互信（mpirun 可能从任意执行首节点发起）
并行环境OpenMPI，mpirun --prefix 解决非交互 SSH 的 PATH 问题
应用约束适配BTIO/MADbench 需平方数进程（-n 4 ptile=1）；s3d_io 必须指定 -d 输出目录
作业状态回流门户轮询 bjobs 到 DONE/EXIT，回读 .out 日志解析带宽/GiB/exit code 汇总展示

3. 指标采集

自研 lsf_exporter 调用 bjobs/bhosts 输出 Prometheus 指标（作业状态数、槽位占用、队列分布、24h 完成量），Grafana「LSF HPC 集群总览」15 面板实时展现调度与资源全景。
